# Solar Power Generation Prediction

## Overview

This project predicts solar AC power generation using Machine Learning techniques.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Machine Learning Model

- Linear Regression

## Features

- Data Cleaning
- Feature Engineering
- Data Visualization
- Correlation Analysis
- Power Prediction
- Model Evaluation

## Evaluation Metrics

- MAE
- MSE
- R² Score
- Confusion Matrix
