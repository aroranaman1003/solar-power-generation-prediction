# Solar Power Generation Prediction

## Overview

This project predicts solar AC power generation using Machine Learning techniques on real-world solar plant data. The goal is to analyze plant generation data and predict AC power output using Linear Regression.

## Dataset

The dataset contains solar plant generation information including:

- DATE_TIME
- DC_POWER
- AC_POWER
- DAILY_YIELD
- TOTAL_YIELD
